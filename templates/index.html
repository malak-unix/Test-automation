GUIDE RAPIDE

Ce que fait chaque partie

  1. GitHub Repository URL: depot a analyser, clone en lecture seule.
  2. Target app URL: application deja lancee, par exemple http://localhost:8000.
  3. RAG top k: quantite de contexte envoyee au planner LLM.
  4. MCP active: outils externes standardises utilises quand disponibles.
  5. Artifacts: JSON et rapport HTML generes dans results/runs/.
